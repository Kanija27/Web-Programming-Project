# ResumeIQ – AI-Powered Resume and Career Preparation Platform

## 📌 Project Overview

ResumeIQ is an AI-powered career preparation platform designed to help students and job seekers improve their resumes and prepare for job opportunities. The platform provides an integrated interface for resume analysis and career preparation.

## 🎯 Objectives

- Help users improve their resumes.
- Provide career preparation resources.
- Simplify resume creation and analysis.
- Support users in preparing for interviews.
- Provide a user-friendly interface for career development.

## ✨ Key Features

- **User Authentication:** Login and signup interfaces.
- **Resume Analysis:** Analyze resumes and identify areas for improvement.
- **PDF Upload:** Upload resumes in PDF format.
- **Career Preparation:** Support career planning and job preparation.
- **Responsive UI:** A clean interface built using modern web technologies.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- npm
